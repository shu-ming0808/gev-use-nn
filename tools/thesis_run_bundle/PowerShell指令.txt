Ultra 7 265／16 GB RAM／F槽／Ubuntu-24.04｜緯度新版 2026-10-29

【1. 先關閉其他大型程式，確認所有 WSL／Docker 計算都已停止，再貼這段】
設定：WSL最多10GB、swap4GB、20個CPU；計算程序排程預算8GiB。
這段會備份原設定；wsl --shutdown 會停止所有 WSL，正在計算時不要執行。

& {
    powershell -NoProfile -ExecutionPolicy Bypass -File "F:\論文跑\configure-wsl-16gb.ps1" -Processors 20 -Apply
    if ($LASTEXITCODE -ne 0) { throw '設定失敗，先不要啟動。' }
    wsl --shutdown
    if ($LASTEXITCODE -ne 0) { throw 'WSL沒有正常停止。' }
    wsl -d Ubuntu-24.04 --exec nproc
    wsl -d Ubuntu-24.04 --exec free -h
}

nproc應顯示20。16GB主機給WSL最多10GB，名目上剩約6GB給Windows；背景程式仍會爭用記憶體。
若整機重開、過熱或大量換頁，先停下檢查，不關保護硬跑。

【2. 正式開始：複製這一行】

順序：準備地形＋緯度 → 新版真實EAS NN＋GP → 校準真值 → MLE＋GP → NN＋GP各一次。
緯度只是加入內層選模候選，不強制保留、不重訓NN、不減少GRID。尚未證實會改善RMSE或CRPS。
這次必須重跑新版真實EAS；舊版未加入緯度的26小時結果不能冒充新版結果。
中斷後貼同一行：完整且校驗一致的階段跳過，未完成GP不能從半個fold續跑。
確認一次完成後才把replicates改成100。不要同時開兩份流程。
